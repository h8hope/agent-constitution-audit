# Agent Constitution Audit

Audit an AI agent's stacked rule layers (identity/instruction/memory/skills) for conflicts, drift and honesty gaps. Read-only, evidence-based; works with Claude Code, Codex CLI, OpenCode, Hermes and other markdown-driven agents.

Cross-agent `SKILL.md` (YAML frontmatter + markdown instructions). Install: copy this folder into your agent's skills directory (e.g. `~/.claude/skills/`, `~/.cod/skills/`); any SKILL.md-compatible agent loads it automatically.
